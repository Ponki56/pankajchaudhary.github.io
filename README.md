# Pankaj Chaudhary — GitHub Pages profile

A responsive academic profile website built with plain HTML and CSS.

## Before publishing
1. Open `index.html`.
2. Find `YOUR-LINKEDIN-USERNAME` and replace it with your LinkedIn profile URL or username.
3. Review the research profile, methods/tools, and research-interest wording so it accurately reflects your current work.
4. Save the file.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository**. For a personal site, name it `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html` to the repository's root. You can also upload this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes and open `https://YOUR-USERNAME.github.io`.

If you use a repository with another name, such as `research-profile`, the page will usually be at `https://YOUR-USERNAME.github.io/research-profile/`.
